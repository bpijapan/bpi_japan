BPI JAPAN website upload package

【重要】
このZIPは、写真・動画が消えにくいように、
index.html / style.css / script.js / 画像 / 動画をすべて同じ階層に置いた版です。

GitHubにアップロードするときは、ZIPを解凍して、
中のファイルをすべてリポジトリ直下にアップロードしてください。
「bpi_site_flat_upload」フォルダごとではなく、中身だけを入れてください。

アップロード必須:
- index.html
- style.css
- script.js
- bpi_cm_hero.mp4
- bpi_poster.jpg
- bpi_logo_horizontal.png
- bpi_logo_endcard_16x9.png
- coach_male.png
- coach_female.png
- bpi_contact.jpg
